# hs-geometric-arrest

Tangential Voronoi cells as geometric ground states for hard spheres: exact
enumeration in three dimensions, derivation of the depleted-lattice ladder, and
the machinery to test the mechanism. Built from the handoff bundle in
`../hs-geometric-arrest-handoff/` following `CLAUDE_CODE_TASKS.md` (T0-T12).

This README is completed as the build proceeds (T0 scaffold committed first,
per the task list); the final version documents exactly what exists and what
has been executed.
